# Komentář k zákonu č. 277/2013 Sb., o směnárenské činnosti

Otevřený komentář k zákonu o směnárenské činnosti — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; směnárník a povolení ČNB, podmínky provozování směnárenské činnosti, kurzovní lístek a informační povinnosti, odstoupení od směnárenského obchodu, dohled a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2013-00277_2021-10-01`.
